## Descrição do Projeto

Este repositório contém o e-book acadêmico desenvolvido como atividade de avaliação final. O trabalho aborda de forma clara, organizada e contextualizada as implicações éticas do uso de ferramentas de Inteligência Artificial no cotidiano escolar, universitário e profissional.

O e-book foi formatado estritamente dentro das normas técnicas brasileiras:
- **ABNT NBR 14724:** Estrutura de trabalhos acadêmicos (Capa, Folha de Rosto, Sumário, Introdução, Desenvolvimento, Conclusão e Pós-textuais).
- **ABNT NBR 10520:** Regras para citações diretas e indiretas (sistema autor-data).
- **ABNT NBR 6023:** Elaboração da lista de referências bibliográficas.
